# Delivery Partner Daily Workflow

## What Is This?

This is the day-to-day guide for delivery partners — going online, accepting jobs, picking up orders from shops, navigating to customers, confirming delivery, and handling return pickups. This document covers every step of a rider's working day.

---

## Who Uses This?

**Approved delivery partners** actively delivering orders.

---

## What Can You Do?

- Go online and receive delivery job offers
- Accept or skip available jobs
- Navigate to shops and customer addresses
- Confirm pickup and delivery with codes
- Collect cash on delivery from customers
- Handle return pickup and drop trips
- Share live location while delivering

---

## Dashboard

When a rider opens the delivery app, the dashboard shows:

- **Online/offline toggle** — control availability
- **Active order** — current delivery in progress (if any)
- **Available jobs** — nearby delivery opportunities
- **Today's earnings** — how much earned so far today
- **Quick stats** — deliveries completed today

---

## Accepting a Delivery Job

### How jobs appear

When a shop marks an order ready for pickup, the system broadcasts the job to nearby online riders.

### What the rider sees

- Shop name and location
- Customer delivery address
- Distance to shop and to customer
- Estimated earnings for this delivery
- Items summary

### Accept or skip

- **Accept** — job is assigned to this rider; other riders no longer see it
- **Skip** — job remains available for other riders

### Timer

Jobs may have a short acceptance window — if no rider accepts, the system expands the search radius and retries.

---

## Pickup Flow

### Step 1: Navigate to shop

- Rider taps navigate — in-app maps show the route to the shop
- Rider travels to the shop location

### Step 2: Arrive at shop

- Rider taps "Arrived at Shop"
- Shop is notified that rider has arrived

### Step 3: Collect the order

- Shop hands over the packed order
- Rider verifies items match the order summary

### Step 4: Confirm pickup

- Rider taps "Pickup Complete"
- Order status changes to "out for delivery"
- Customer is notified that their order is on the way

---

## Delivery Flow

### Step 1: Navigate to customer

- Rider taps navigate — maps show route to customer's address
- Rider's live location is shared with the customer during this trip

### Step 2: Mark out for delivery

- Status updates to "out for delivery"
- Customer sees rider moving on their tracking map

### Step 3: Arrive at customer

- Rider arrives at the delivery address
- Rider taps "Arrived at Customer"

### Step 4: Delivery code

- Rider requests the delivery code from their app
- Customer sees the code on their order page
- Customer shares the code with the rider
- Rider enters the code in their app

### Step 5: Cash on delivery (if applicable)

- If the order is COD, rider collects cash from the customer
- Amount shown on rider's screen
- Rider confirms cash collected

### Step 6: Complete delivery

- Rider taps "Delivery Complete"
- Order status changes to "Delivered"
- Rider's earnings for this trip are credited
- Customer is notified

---

## Return Pickup Flow

Sometimes riders are assigned to pick up returned items from customers and bring them back to shops.

### Step 1: Accept return pickup job

- Rider sees a return pickup notification
- Rider accepts the job

### Step 2: Go to customer

- Navigate to customer's address
- Customer has a **pickup code** ready

### Step 3: Verify pickup

- Rider enters the pickup code from the customer
- Rider may take a photo of the item as proof
- Rider collects the returned item

### Step 4: Go to shop

- Navigate to the seller's shop
- Deliver the returned item

### Step 5: Verify drop

- Rider enters the **drop code** at the shop
- Return is confirmed complete
- Customer's refund is processed

## GPS and Live Location

### Automatic location sharing

While a rider has an active delivery:

- Their phone sends location updates automatically
- Customer sees the rider on a live map
- Admin can see the rider on the fleet map
- Seller can track progress on their order screen

### When location sharing stops

- After delivery is confirmed
- When rider goes offline
- After a set time if no active delivery

---

## Navigation

The delivery app includes in-app navigation:

- Route from current location to shop
- Route from shop to customer
- Turn-by-turn directions via maps service
- Estimated time and distance

---

## What Happens Behind the Scenes

- Job broadcast goes to all online riders within search radius
- First rider to accept gets the job
- Location updates stream to live location service during active delivery
- Delivery code verification prevents fake deliveries
- COD cash is recorded as "cash in hand" on rider's account
- Earnings credited immediately on delivery confirmation

---

## Important Rules

- Only accept jobs you can complete — cancelling after accepting affects your rating
- Always verify delivery code — never mark delivered without it
- Collect exact COD amount shown on screen
- Keep location sharing on during active deliveries
- Return pickup items must be delivered back to the correct shop
- One active delivery at a time

---

## What If Something Goes Wrong?

| Problem                              | What to do                                                   |
| ------------------------------------ | ------------------------------------------------------------ |
| Cannot find shop                     | Use navigation; call shop using contact in app               |
| Cannot find customer address         | Call customer; use support if needed                         |
| Customer not available               | Wait reasonable time; contact support                        |
| Customer does not have delivery code | Customer checks their order page; rider can request new code |
| Wrong items at shop                  | Contact support before picking up                            |
| Customer refuses COD payment         | Do not deliver; contact support                              |
