# Seller Onboarding and Store

## What Is This?

Before a shop can sell on the platform, the seller must sign up, verify their identity, get admin approval, and set up their shop profile. This document explains the full seller onboarding process and shop setup.

---

## Who Uses This?

**New and existing sellers** (shop owners) joining the platform.

---

## What Can You Do?

- Sign up with shop details, phone, and email
- Verify phone and email with codes
- Submit application for admin approval
- Set up shop profile, location, and bank details
- View dashboard with today's orders and revenue

---

## Sign Up Flow

### Step-by-step

1. **Enter shop details**
   - Shop name
   - Shop description
   - Business category

2. **Enter contact information**
   - Phone number (used for login)
   - Email address

3. **Verify phone**
   - System sends text message code
   - Seller enters code to confirm phone

4. **Verify email**
   - System sends email code
   - Seller enters code to confirm email

5. **Submit application**
   - Application goes to admin for review

6. **Wait for approval**
   - Seller sees a "pending approval" screen
   - Cannot list products or receive orders yet

7. **Admin approves or rejects**
   - If approved: full seller portal unlocks
   - If rejected: seller is notified with reason

---

## Pending Approval Screen

While waiting, the seller can see:

- Application status (pending)
- Message explaining that admin is reviewing
- Contact information for support if needed

The seller **cannot**:

- Add products
- Receive orders
- Access earnings or analytics

---

## Shop Profile Setup

Once approved, seller should complete their shop profile:

### Shop information

- **Shop name** — displayed to customers
- **Description** — what the shop sells
- **Logo** — shop image shown to customers
- **Operating hours** — when the shop accepts orders

### Shop location

- **Address on map** — critical for delivery distance calculation
- The more accurate the location, the more accurate delivery fees and rider assignment

### Bank details

- Account for receiving earnings withdrawals
- Account holder name, account number, IFSC code

---

## Seller Dashboard

After approval, the seller's home screen shows:

### Key metrics

- Today's orders count
- Today's revenue
- Pending orders needing action

### New order alerts

When a customer places an order, the seller gets:

- A sound or popup notification
- Order details (items, customer address, payment type)
- An **Accept** button with a countdown timer (~60 seconds)

If the seller does not accept within the time limit, the order is automatically cancelled and the customer is refunded.

---

## What Happens Behind the Scenes

- Application is stored and flagged as "pending" for admin
- Admin sees new applications in the pending sellers list
- On approval, seller's account status changes and all features unlock
- Shop location is used to calculate delivery range and fees for customers
- Bank details are used later for withdrawal processing

---

## Important Rules

- Admin approval is required — no seller can operate without it
- Phone number is the login identifier
- Shop location must be accurate — affects delivery and customer reach
- Seller must accept orders within ~60 seconds or they auto-cancel
- One shop per seller account (typically)

---

## What If Something Goes Wrong?

| Problem              | What happens                                                |
| -------------------- | ----------------------------------------------------------- |
| Application rejected | Seller notified with reason; may reapply or contact support |
| Approval taking long | Seller can contact admin or support                         |
| Wrong shop location  | Update in profile — affects future orders only              |
| Cannot log in        | Use phone + text code; contact support if blocked           |
