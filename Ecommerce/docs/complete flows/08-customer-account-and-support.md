# Customer Account and Support

## What Is This?

Everything related to the customer's personal account — signing up, logging in, managing profile and addresses, getting help through support chat, leaving product reviews, and managing notifications. This document covers the full customer account experience.

---

## Who Uses This?

**Customers** managing their personal account and getting help.

---

## What Can You Do?

- Sign up and log in with phone number
- View and edit profile
- Manage saved delivery addresses
- Adjust notification settings
- Create and reply to support tickets
- Rate and review products
- View in-app notifications
- Read terms, privacy policy, and about pages

---

## Sign Up and Login

### How it works

Customers do not use passwords. They log in with their **phone number** and a **text message code**.

### Sign up flow

1. Customer enters phone number
2. System sends a text message with a code
3. Customer enters the code
4. Customer fills in name and optional email
5. Account is created — customer is logged in

### Login flow

1. Customer enters phone number
2. System sends a text message with a code
3. Customer enters the code
4. Customer is logged in

### Rules

- One account per phone number
- Text codes expire after a few minutes
- Too many wrong attempts may temporarily block login
- No password to forget — always phone + code

## Profile

### What customers can manage

- **Name** — display name on orders and support
- **Email** — optional, for receipts and communication
- **Phone** — login identifier (usually cannot be changed easily)
- **Profile photo** — if supported

### Edit profile

Customer goes to profile → edit, makes changes, and saves.

---

## Saved Addresses

Customers can save multiple delivery addresses for quick checkout.

### Managing addresses

- **Add** — new address with label (Home, Office, etc.), full address, pin code
- **Edit** — change any saved address
- **Delete** — remove addresses no longer needed
- **Set default** — one address auto-selected at checkout

### How addresses are used

- Selected address at checkout determines delivery fee and shop availability
- Address is shown to the delivery partner for navigation
- Address is stored securely and only visible to the customer, assigned rider, and admin

## Settings

### Notification preferences

Customers can control:

- Push notifications on/off
- Order update alerts
- Promotional messages

Settings are accessed from the profile or settings page.

## Support Tickets

### What are support tickets?

A chat-style help system where customers describe a problem and the support team responds.

### How to get help

1. Customer goes to Support page
2. Customer selects a topic or describes the issue
3. Customer creates a new ticket
4. Support team sees the ticket in admin console
5. Back-and-forth messages until resolved
6. Customer sees unread indicator when admin replies

### Real-time updates

When admin replies, customer sees the new message instantly without refreshing — similar to a chat app.

### Common support topics

- Order not delivered
- Wrong items received
- Payment issue
- Refund not received
- Account problem
- General question

---

## Product Reviews

### Leaving a review

After an order is delivered, customers can rate and review products they bought.

### How it works

1. Customer opens a delivered order or product page
2. Customer gives a star rating (1–5) and writes a review
3. Review is submitted for moderation
4. Admin approves or rejects the review
5. Approved reviews appear on the product page for other customers

### Rules

- Usually only customers who bought the product can review it
- Reviews must be approved before they are public
- Inappropriate reviews are rejected by admin

---

## Notifications

### In-app notifications

A bell icon in the header shows notification count. Tapping opens the notification list with order updates, promotions, and support replies.

### Push notifications

If customer allows notifications on their phone, they receive alerts even when the app is closed:

- Order confirmed
- Rider on the way
- Order delivered
- Support reply received
- Promotional offers

---

## Legal Pages

The customer app includes standard legal pages:

- **Terms of Service** — rules for using the platform
- **Privacy Policy** — how customer data is handled
- **About** — information about the business

These are managed by admin and displayed to all customers.

---

## Chat Page

Some platforms include a dedicated chat page for real-time support conversations, connected to the support ticket system.

---

## What Happens Behind the Scenes

- Login codes are sent via text message service
- Profile changes are saved immediately
- Support messages are delivered in real time to both customer and admin
- Reviews go into a moderation queue for admin approval
- Push notifications are sent through the phone notification service

---

## Important Rules

- Phone number is the unique identifier — one account per number
- Addresses affect product availability — keep them accurate
- Support tickets are private — only customer and admin can see them
- Reviews are moderated — not all reviews appear immediately

---

## What If Something Goes Wrong?

| Problem                    | What to do                                        |
| -------------------------- | ------------------------------------------------- |
| Did not receive login code | Wait a minute and retry; check phone number       |
| Cannot log in              | Too many attempts — wait and try again            |
| Support not responding     | Allow time; create a new ticket if needed         |
| Review not showing         | It may be pending admin approval                  |
| Notifications not arriving | Check notification settings and phone permissions |
