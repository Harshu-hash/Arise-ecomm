# Delivery Partner Onboarding

## What Is This?

Before someone can deliver orders on the platform, they must sign up, upload required documents, get admin approval, and set up their profile. This document explains the full delivery partner onboarding process.

---

## Who Uses This?

**New and existing delivery partners** (riders) joining the platform.

---

## What Can You Do?

- Sign up with phone number and personal details
- Upload identity and vehicle documents
- Set up bank account for earnings
- Submit application for admin approval
- Manage profile, vehicle info, and documents after approval

---

## Sign Up Flow

### Step-by-step

1. **Enter personal details**
   - Full name
   - Phone number (used for login)
   - Date of birth

2. **Verify phone**
   - System sends text message code
   - Rider enters code to confirm

3. **Upload documents**
   - Government ID (Aadhaar, PAN, driving license, etc.)
   - Profile photo
   - Vehicle registration document
   - Vehicle photo

4. **Enter vehicle information**
   - Vehicle type (bike, scooter, bicycle, etc.)
   - Registration number
   - Model and color

5. **Enter bank details**
   - Account holder name
   - Account number
   - IFSC code
   - For receiving earnings withdrawals

6. **Submit application**
   - Application goes to admin for review

7. **Wait for approval**
   - Rider sees a "pending approval" screen
   - Cannot receive delivery jobs yet

8. **Admin approves or rejects**
   - If approved: rider can go online and accept jobs
   - If rejected: rider is notified with reason

---

## Pending Approval Screen

While waiting, the rider sees:

- Application status (pending)
- Message that admin is reviewing documents
- Support contact if needed

The rider **cannot**:

- Go online
- See or accept delivery jobs
- Earn money

---

## Profile Sections

After approval, riders manage their profile across several sections:

### Personal details

- Name, phone, email
- Emergency contact
- Profile photo

### Vehicle information

- Vehicle type, registration number
- Model, color
- Update if vehicle changes

### Bank account

- Account details for withdrawals
- Update if bank account changes

### Documents

- View uploaded documents
- Re-upload if expired or rejected
- Add new documents if required

### Safety and privacy

- Safety guidelines for delivery
- Privacy settings
- Location sharing preferences

### Settings

- Notification preferences
- App preferences
- Language settings

### Help and support

- FAQ for delivery partners
- Contact support
- Report an issue

---

## Going Online

Once approved, the rider controls their availability:

### Online

- Rider taps "Go Online"
- Rider appears in the system's available pool
- Rider starts receiving delivery job notifications
- Rider's location is shared for job matching

### Offline

- Rider taps "Go Offline"
- Rider stops receiving new job notifications
- Active delivery (if any) must still be completed
- Location sharing stops for new jobs

### Rules

- Only online riders receive delivery offers
- Rider should be online only when available to deliver
- Going offline during an active delivery does not cancel the delivery

---

## What Happens Behind the Scenes

- Documents are stored securely and visible to admin for review
- Admin sees pending applications in the delivery partners section
- On approval, rider status changes and all features unlock
- Online/offline status is tracked in real time for job matching
- Rider location (when online) is used to find the nearest rider for each order

---

## Important Rules

- Admin approval is required before delivering
- All documents must be valid and current
- Phone number is the login identifier
- Rider must go online to receive jobs
- One active delivery at a time (typically)
- Bank details required before first withdrawal

---

## What If Something Goes Wrong?

| Problem              | What happens                                                        |
| -------------------- | ------------------------------------------------------------------- |
| Application rejected | Rider notified with reason; may reapply with corrected documents    |
| Documents expired    | Rider must upload new documents; may be taken offline until updated |
| Cannot go online     | Check approval status; contact support                              |
| Wrong bank details   | Update in profile before requesting withdrawal                      |
